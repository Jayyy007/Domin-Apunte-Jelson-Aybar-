IMPORTANTE PARA EL MICROFONO:
GitHub Pages publica el sitio por HTTPS, que es necesario para solicitar acceso al microfono. Al pulsar el boton de microfono, la pagina solicita permiso al navegador mediante getUserMedia y luego inicia el reconocimiento de voz.

PUBLICAR EN GITHUB:
1. Crea o abre un repositorio.
2. Sube index.html, manifest.webmanifest, sw.js y la carpeta icons.
3. Ve a Settings > Pages.
4. Selecciona Deploy from a branch, elige la rama (normalmente main) y la carpeta /root.
5. Guarda y abre la URL HTTPS de GitHub Pages.
6. Pulsa el microfono y acepta el permiso de microfono.

Nota: el reconocimiento de voz depende del navegador/dispositivo. Chrome/Chromium en Android suele ofrecer mejor compatibilidad.
